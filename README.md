# Modern C++ Mastery: 60 Architectural & Systems Programming Challenges

A curated collection of 60 progressive programs focused on **Modern C++ (C++20)**, **software architecture**, and **embedded systems development**, emphasizing idiomatic, safe, and high-performance code.

---

## Roadmap & Modules

| Module | Core Topics | Objective |
| :--- | :--- | :--- |
| **1. Fundamentals & Logic** | Syntax, Control Flow, Functions | Write safe basic programs mastering types, operators, and loops. |
| **2. Structured Data** | Arrays, `std::array`, Strings, Enums | Handle structured data, buffers, text, and states natively. |
| **3. Memory & Pointers** | Pointers, References, Dynamic Memory, UB, Memory Safety | Master memory addresses, lifetime, ownership, and safety. |
| **4. OOP & Resource Management** | Classes, Constructors/Destructors, Copy/Move, Rule of 0/3/5, Smart Pointers, RAII | Deeply understand object lifecycles, ownership, and resource control. |
| **5. STL & Generics** | Containers, Algorithms, Iterators, Ranges, Lambdas, Templates, `auto` | Solve problems idiomatically using the Standard Library and generics. |
| **6. Modern C++ & Abstraction** | Inheritance, Polymorphism, `constexpr`, Operators, Exceptions, Architecture | Build clear, robust abstractions using modern language features. |
| **7. Software Engineering** | Headers, Namespaces, Build Systems, CMake, Debugging | Transform isolated code into organized, buildable, and debuggable projects. |
| **8. Embedded Systems** | Embedded C++, C/C++ Integration, RTOS, Applied Firmware | Apply C++ in resource-constrained firmware, HALs, and real-time systems. |
